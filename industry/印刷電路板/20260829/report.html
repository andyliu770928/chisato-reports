研究範圍：全球PCB市場、台灣供應鏈、重點廠商

資料基準：2024-2025年數據（部分2026年最新動態）

Executive Summary

印刷電路板（PCB）為電子產品之母，承載IC與電子元件的電路連接。2024年全球PCB市場規模約達870億美元，2025年預估突破900億美元，2026-2029年間之年複合成長率（CAGR）維持在5-7%區間。市場成長核心驅動力來自三大面向：其一，AI伺服器與資料中心對高層數（HDI）、高頻高速電路板需求爆發；其二，電動車滲透率持續提升帶動車用PCB量價齊揚；其三，消費性電子庫存調整告一段落，智慧手機與PC重啟拉貨動能。台灣PCB產業以欣興（3037）、景碩（3189）、華通（2342）、南電（8056）、臻鼎-KY（4958）為首，在AI伺服器ABF載板、HDI手機板、汽車雷達板等高階應用居全球領導地位。本報告深度分析全球PCB市場結構、技術演进趨勢、台灣供應鏈競爭態勢，並提供個股基本面追蹤。

一、全球PCB市場概況

1.1 市場規模

根據Prismark、Gartner及多家研究機構資料，2024年全球PCB市場規模約870億美元，2025年預估達901億美元，2029年有機會突破1,200億美元（CAGR約6.8%）。若加計PCB下游電子整機市場，產值鏈規模更高達數千億美元。

亞太地區為全球最大PCB市場，佔整體產值約88%，其中中國（含台灣、日本、韓國）佔比最高。中國仍是最大生產國，但近年受地緣政治與成本壓力影響，部分訂單開始向東南亞（泰國、越南、印度）與印度分流。

各區域市場佔比（2024年預估）：

  • 亞太（含中國）：~88%
  • 美洲：~6-7%
  • 歐洲：~5%

1.2 產品類別結構

PCB依用途分為剛性板（RPCB）、軟板（FPC）、軟硬結合板（Rigid-Flex）、HDI板、IC載板（Substrate）等。2024年市場結構大致如下：

產品類別佔比主要應用成長率
多層板（4-16層）~35%消費電子、汽車3-4%
HDI板~20%智慧手機、汽車電子8-10%
撓性板（FPC）~15%智慧手機、穿戴裝置5-7%
IC載板（Substrate）~18%CPU/GPU/AI晶片、先進封裝12-15%
射頻/汽車板~8%5G基地台、車用雷達10%+

成長最快的細分市場：IC載板（ABF載板），主要由AI GPU、先進封裝（CoWoS、SoIC）需求帶動。

1.3 關鍵驅動因素

（1）AI伺服器與資料中心

輝達（NVIDIA）H100/H200/B100系列、AMD MI300X、Google TPU、AWS Trainium等AI加速器需要大量高層數PCB與ABF載板。單台AI伺服器PCB價值量為傳統伺服器的5-10倍，為PCB產業帶來結構性成長動能。

（2）電動車（EV）

電動車PCB用量為傳統燃油車的3-4倍，主要用於 Battery Management System（BMS）、馬達驅動、ADAS系統。先進駕駛輔助系統（ADAS） Level 2以上車款需使用高頻雷達板與光達（Lidar）PCB，規格要求極高。

（3）5G與物聯網

5G基地台天线（AAU）需使用高頻高速PCB，射頻板材要求升級至Low Dk/Df等級。物聯網裝置爆發則帶動FPC與Mini-LED PCB需求。

（4）消費性電子復甦

智慧手機出貨量2024年回穩至約12億支，2025年温和增長。摺疊手機滲透率提升帶動FPC與HDI規格升級。PC市場在庫存調整結束後重啟拉貨。

二、技術發展趨勢

2.1 高層數電路板（High-Layer Count PCB）

AI伺服器PCB層數從傳統伺服器的12-16層提升至24-40層，線寬線距要求達到2/2mil甚至1/1mil以下。主要技術挑戰包括：

  • Thermal Management：高功率元件散熱需求帶動厚銅箔、厚銅鍍工藝
  • Ultra-low Dk/Df材料：高速訊號傳輸需使用Low Dk/Df無鹵材料（如M6、M7等級）
  • 埋孔與盲孔技術：微孔加工能力從機械鑽孔轉向雷射孔（Laser Via）

2.2 ABF（Aju Build-up Film）載板

ABF載板為IC與PCB之間的關鍵介面，AI時代需求爆發。

市場規模： 2024年全球ABF載板市場約55-60億美元，2025年預估突破70億美元，CAGR達15-20%。

主要應用：

  • GPU（輝達H100/H200/B100/AMD MI300X）
  • CPU（Intel Sapphire Rapids、AMD EPYC）
  • 網路晶片（Broadcom、Marvell）
  • 異質整合先進封裝（CoWoS、SoIC、Foveros）

技術演進：

  • 線寬/線距：從15μm收窄至5-8μm
  • 載板尺寸：從70×70mm擴大至100×100mm以上
  • 層數：從4-6層提升至8-14層
  • 細微化：Chip-first / Chip-last工藝持續演進

2.3 車用PCB規格升級

車用PCB正從傳統2-4層板升級至高多層（HDI）與厚銅製品：

  • ADAS感測器：77GHz/79GHz毫米波雷達板、8-12層微波板
  • BMS（電池管理系統）：12-16層厚銅板（3-6oz）
  • 車載資訊娛樂：HDI多層板
  • 車用HPC：未來自駕車中央處理器需要ABF載板

車用PCB認證週期長（IATF 16949）、信賴性要求高，進入障礙高，產品單價（ASP）為消費電子的2-3倍。

2.4 環保與材料趨勢

  • 無鹵素（Halogen-free）材料：環保法規驅動，2025年滲透率預估達60%
  • 高頻低損耗材料：M6/M7等級Low Dk/Df高速材料需求增加
  • 鋁基板：LED照明、功率元件散熱需求穩定
  • 再生材料：響應ESG要求，Panasonic、日立化成推出環保型基板

三、台灣PCB產業分析

3.1 台灣PCB產值概況

台灣為全球最大PCB生產國之一，2024年產值估計約新台幣8,000-8,500億元，全球市佔率（含中國台商）約30-35%。台灣PCB廠商以桃園、新竹、苗栗為主要生產基地，並在中國（華東、華南）、泰國、越南有海外產能布局。

  • 燿華（2383）：軟硬結合板、HDI，汽車板切入供應鏈

汽車板：

四、重點個股深度分析

4.1 南電（8056）——AI載板最大受益者

基本資料： 南電成立於1989年，為南亞塑膠（1303）子公司，持股比例約70%。主要生產ABF載板與系統級封裝（SiP）。

核心業務：

  • ABF載板（佔營收約65-70%）
  • 系統級封裝（SiP，約20%）
  • 傳統PCB（10%）

關鍵客戶：

  • NVIDIA（輝達）：H100/H200/B100系列GPU載板主力供應商
  • AMD：EPYC伺服器CPU、Instinct MI300X
  • Intel：Sapphire Rapids CPU
  • Apple：M系列晶片載板

財務概況（2024年）：

  • 營收：約600億元（新台幣）
  • 毛利率：預估28-32%（受ABF需求帶動）
  • EPS：預估15-20元

成長動能：

1. NVIDIA H100/H200持續放量，B100/GB200即將量產

2. 異質整合CoWoS封裝需求爆發，先進封裝增加載板面積

3. 聯發科、Novatek等AI ASIC客戶開案量增加

4. 新一代ABF載板（M7等级）通過認證，ASP提升

主要風險：

  • 景氣波動影響消費性電子需求
  • 中國競爭對手（如深南電路、興森快捷）加速追趕
  • 新產能開出時程若延誤可能流失份額

4.2 景碩（3189）——ABF二哥，訂單能見度高

基本資料： 景碩成立於1990年，為友達集團旗下子公司。主要生產ABF載板、BT載板、Module板。

核心業務：

  • ABF載板（佔營收約50%）
  • BT載板（PA模組、RF模組用）
  • 記憶體模組板

關鍵客戶：

  • NVIDIA（輝達）：主要AI載板供應商之一
  • AMD：伺服器CPU載板
  • 高通（Qualcomm）：手機晶片載板
  • 聯發科（2454）：手機SoC載板

成長動能：

1. ABF載板新產能陸續開出（楊梅新廠）

2. NVIDIA B100/GB200系列載板認證通過

3. 手機Sub-6G與毫米波射頻模組需求回溫

4. AI ASIC客戶分散供應商策略有利景碩

主要風險：

  • 客戶集中度過高（NVIDIA佔比持續上升）
  • 新廠折舊壓力
  • PCB整體景氣波動

4.3 華通（2342）——HDI手機板龍頭

基本資料： 華通成立於1965年，為老牌PCB廠。核心產品為HDI板、軟板、軟硬結合板。主要生產基地位於台灣（蘆竹、大園）與中國（惠州）。

核心業務：

  • HDI板（佔營收約60%）：智慧手機主板
  • 軟板（FPC，約25%）：顯示器模組、電池模組
  • 軟硬結合板（~10%）：穿戴裝置、醫療

關鍵客戶：

  • Apple：iPhone、iPad、Mac主板主力供應商
  • Samsung：旗艦手機HDI板
  • Sony：遊戲主機、相關消費電子

成長動能：

1. 蘋果iPhone 17系列HDI規格升級

2. 摺疊手機滲透率提升（Samsung Galaxy Fold/Flip）

3. 軟板切入車載供應鏈（Tier 1認證中）

4. 低軌衛星PCB板開始出貨

主要風險：

  • 蘋果供應商競爭激烈，議價壓力
  • 智慧手機市場成長放緩
  • 地緣政治風險（中國產能）

4.4 敬鵬（3041）——汽車PCB龍頭

基本資料： 敬鵬成立於1985年，為全球最大汽車PCB廠，客戶涵蓋全球前20大車廠。泰國廠為主要生產基地，台灣桃園、中國常熟有產能。

核心業務：

  • 汽車板（佔營收約80%+）：傳統多層板到HDI
  • 消費性電子（約15%）
  • 其他（約5%）

關鍵客戶：

  • Bosch、Continental、Valeo、Denso等全球Tier 1車電廠
  • Tesla：電動車供應鏈
  • 傳統車廠：BMW、Mercedes-Benz、VW、GM、Toyota

成長動能：

1. 電動車PCB用量為燃油車3-4倍

2. ADAS Level 2+滲透率提升，帶動高規雷達板

3. BMS（電池管理系統）厚銅板需求增加

4. 泰國產能擴充，贴近東協市場

主要風險：

  • 汽車產業景氣波動（2024-2025年歐美車廠罷工、中國市場內捲）
  • 認證週期長，新訂單放量需時
  • 成本壓力（原材料銅價、工资上涨）

4.5 臻鼎-KY（4958）——全球最大PCB集團

基本資料： 臻鼎為鴻海集團旗下PCB事業，旗下有鹏鼎、礼鼎、恒bone等多家子公司。生產基地涵蓋台灣、中國、印度。

核心業務：

  • 軟板（FPC，約40%）
  • 類載板（SLP，約25%）
  • HDI板（~20%）
  • 汽車/其他（~15%）

關鍵客戶：

  • Apple（最大客戶）：iPhone、Mac、iPad、Apple Watch
  • 三星
  • 華為
  • Tesla

成長動能：

1. 蘋果iPhone 17主板升級SLP

2. 汽車PCB切入Tesla、BMW等供應鏈

3. 印度新廠投產，因應供應鏈多元化需求

4. AI伺服器PCB開始認證

主要風險：

  • 蘋果佔比過高（~70%），客户集中風險
  • 地緣政治影響中國產能
  • 消費電子景氣波動

五、產業供給與產能動態

5.1 全球PCB產能分布

全球PCB產能高度集中於亞太地區（中國、臺灣、韓國、日本）。近年因地緣政治與供應鏈韌性考量，呈現「中國+N」（N=台灣/泰國/印度/越南）布局趨勢。

主要擴產地區：

  • 泰國：成為汽車PCB新建廠首選地，敬鵬、欣興、華通、定穎、燿華相繼宣布泰國建廠計畫
  • 印度：鴻海/臻鼎在印度建廠，因應蘋果供應鏈多元化
  • 越南：軟板、FPC供應鏈转移
  • 台灣：高階ABF載板、HDI板擴產

5.2 ABF載板供需分析

供給端： 南電、景碩、欣興三家台廠加上日本揖斐電（Ibiden）、韓國三星电机（SEMCO）、大德電子（Daeduck），為全球ABF載板主要供應商。台灣三雄合計市佔約35-40%。

需求端： AI GPU需求爆發，預計2025-2026年ABF載板仍處於供給緊張狀態。NVIDIA对載板的需求持續超過供應能力，載板廠話語權強。

供需缺口評估： 2024-2025年ABF載板供需比預估維持在90-95%，部分緊缺規格（如大尺寸、高層數）供需更緊張。

六、2025-2026年展望與投資建議

6.1 總體展望

2025年PCB產業温和復甦，2026年展望正向。

  • AI伺服器： 需求維持高度暢旺，NVIDIA B100/GB200量產曲線陡峭
  • 消費性電子： 智慧手機温和增長，PC庫存回歸正常
  • 汽車： 電動車滲透率持續提升，但傳統車廠面臨壓力
  • 網通： 5G基礎建設持續布建，800G交換器需求興起

6.2 投資建議

首選標的（AI受益）：

  • 南電（8056）：ABF載板最大受益者，NVIDIA核心供應商，目標價上看500元+
  • 景碩（3189）：ABF二哥，訂單能見度佳，目標價250元+

次選標的（汽車/復甦）：

  • 敬鵬（3041）：汽車PCB龍頭，EV長期受益，估值修復機會
  • 華通（2342）：iPhone規格升級受益，殖利率稳定

高風險高報酬：

  • 燿華（2383）：汽車HDI切入、營運轉機

上游材料（隱形冠軍）：

  • 台光電（2383）：PCB銅箔基板材料，供不應求

6.3 風險提示

1. 庫存調整風險： 消費性電子PCB可能再现库存修正

2. 地緣政治風險： 中美貿易摩擦影響中国产能利用率

3. 景氣波動： 全球經濟放緩抑制電子產品需求

4. 技術替代： 光學PCB（光纖）等新技術威脅

5. 人才短缺： 台灣PCB產業面臨技術人才不足
