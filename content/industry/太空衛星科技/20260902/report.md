# 太空衛星科技產業報告

**報告日期：2026年9月2日**
**研究深度：產業全景分析**

---

## Executive Summary

太空衛星產業正從「國家主導」轉向「商業驅動」，成為全球科技競爭最激烈的新戰場。2025年全球太空經濟市場規模達4,391億美元，2035年預估突破8,518億美元，年複合成長率7%。低軌衛星（LEO）為核心增長引擎，2025年市場118億美元，2030年將翻升至206億美元。手機直連衛星（Direct-to-Device）新興服務2026年市場規模達76億美元，年增49%，為最新商業爆發點。

台灣已有55家廠商切入國際衛星供應鏈，2025年衛星地面設備產值達新台幣2,771億元，年增13%。我國自製B5G低軌通訊衛星預計2027年發射，中華電信OneWeb服務已進入商業營運階段，台灣正式從「地面設備供應」升級為「系統整合參與者」。

## 2. 產業結構與價值鏈

### 2.1 上中下游分工

```
上游：設備製造
├── 零組件/材料（PCB、CCL、天線、晶片）
├── 次系統（太陽能板、推進系統、ADCS）
└── 整機（衛星本體製造）

中游：發射與營運
├── 發射服務（SpaceX、Rocket Lab）
├── 衛星星座營運（Starlink、Kuiper、OneWeb）
└── 地面站與網路管理

下游：應用服務
├── 衛星寬頻通訊
├── 地球觀測與遙測
├── 導航定位
└── 手機直連衛星（D2D）
```

## 3. 低軌衛星（LEO）競爭態勢

### 3.1 四大巨頭佈局

| 營運商 | 背景 | 衛星數量 | 現況 |
|--------|------|----------|------|
| Starlink | SpaceX（馬斯克） | 近7,000顆（目標2.8萬顆） | 用戶逾900萬，領先地位 |
| Project Kuiper | 亞馬遜 | 約180顆（目標3,000+顆） | 2026年中商業服務 |
| OneWeb | Eutelsat（英國/法國） | 634顆（+340顆擴充） | 全球覆蓋達成 |
| Lightspeed | Telesat（加拿大） | 298顆（預計2028年商用） | 進度落後 |

### 3.2 關鍵技術趨勢

- **雷射星間鏈路（ISL）**：提升傳輸效率，已成LEO標準標配
- **相位陣列天線（Phased Array Antenna）**：成本瓶頸突破，終端設備加速普及
- **手機直連衛星（D2D）**：2026年最大商業爆發點，結合5G/6G NTN標準
- **可重複使用火箭**：大幅降低發射成本，Starlink單次發射提升至6000顆

### 3.3 手機直連衛星市場

- 2026年市場規模：76億美元，年增49%
- 主要推動者：Starlink（Direct-to-Cell）、AST SpaceMobile
- 台灣聯發科已宣布與Starlink合作，展示行動裝置緊急衛星通訊

### 4.3 台灣政策推進

**太空三期2.0計畫（國科會主導）：**
- 總經費：新台幣710億元（至2031年）
- 核心目標：2027年發射首顆自製B5G低軌通訊衛星（B5G-1A）
- 第二顆B5G-1B：2030年完成
- 其餘4顆：由經濟部與國內廠商共同主導建造

**重要里程碑：**
- 2025年11月：「齊柏林衛星」發射，逾20家台灣廠商參與，國產自製率達84%

**中華電信OneWeb：**
- 2025年6月取得商用許可執照
- 2026年正式進入商業推廣階段
- 定位：海纜備援電信B2B/B2G服務

## 6. 總結

### 產業趨勢

1. **LEO為核心戰場**：低軌衛星從通訊擴展至遙測、導航、手機直連，應用場景持續擴大
2. **商業化成熟**：Starlink用戶突破900萬，亞馬遜Kuiper 2026年加入競爭，市場即將進入巨頭競爭階段
3. **D2D爆發**：手機直連衛星為2026年最大黑馬，結合5G/6G標準重塑行動通訊
4. **台灣角色升級**：從零組件供應商升級至系統整合參與者，政策支持B5G自製衛星
