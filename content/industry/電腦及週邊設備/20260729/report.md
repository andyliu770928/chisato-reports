## 1. 產業概述

### 1.1 產業定義與範疇

「電腦及週邊設備」產業涵蓋以下主要產品類別：

- **個人電腦（PC）**：桌上型電腦（Desktop）、筆記型電腦（Notebook/Laptop）
- **平板電腦（Tablet）**
- **伺服器（Server）**：包括企業級伺服器、資料中心伺服器
- **週邊設備**：顯示器、印表機、鍵盤、滑鼠、儲存設備、網通設備
- **工業電腦（IPC）**：嵌入式系統、POS系統、ATM等

### 1.2 台灣產業地位

台灣是全球資通訊（ICT）產業的重要製造基地，尤其在筆記型電腦（NB）和伺服器製造領域占據主導地位。根據台灣經濟部統計，台灣在全球筆記型電腦代工市場佔有率超過90%，伺服器代工市佔率約80%，被譽為「護國群山」之一。

## 3. 主要驅動因素

### 3.1 AI PC（人工智慧個人電腦）

AI PC是2024-2025年產業最重要的驅動因素之一。

**市場定義**：AI PC指內建NPU（神經網路處理單元）、能夠執行本地AI運算的個人電腦，通常配備專門的AI加速器（如Intel Core Ultra、AMD Ryzen AI、高通Snapdragon X系列）。

**市場規模預測**：
- 2024年：AI PC出貨量約4,000萬台，滲透率16%
- 2025年：預計出貨量達8,000-1億台，滲透率提升至32-40%
- 2026年：預計滲透率超過50%

**關鍵影響**：
1. **硬體升級需求**：NPU、更多核心、更強散熱系統
2. **平均售價（ASP）提升**：AI PC單價較傳統PC高20-40%
3. **軟體生態系**：Windows 11 AI功能、Copilot+ PC標準

**主要晶片供應商**：
- Intel（Core Ultra系列）
- AMD（Ryzen AI 300系列）
- Qualcomm（Snapdragon X Elite）
- Apple（M4系列）

### 3.2 邊緣運算（Edge Computing）

邊緣運算將運算能力推向網路邊緣，減少延遲並提升資料隱私。

**驅動因素**：
- 物聯網（IoT）設備數量爆增（預計2025年超過300億台）
- 自動駕駛、智慧製造、智慧城市的低延遲需求
- 5G網路普及強化邊緣運算能力

**對產業影響**：
- 工業電腦（IPC）需求增加
- 嵌入式系統市場擴大
- 邊緣AI伺服器成長

### 3.3 雲端資料中心擴張

大型雲端服務商（CSP）持續擴充資料中心基礎設施。

**主要投資者**：
- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)
- Meta、Microsoft在AI基礎設施的巨額投資

**市場規模**：
- 2024年全球資料中心市場規模：約2,500億美元
- AI訓練與推論伺服器需求年增30%以上
- 液冷散熱、先進封裝技術需求爆發

### 3.4 其他驅動因素

| 驅動因素 | 說明 | 影響程度 |
|---------|------|---------|
| 數位轉型 | 企業升級IT基礎設施 | 高 |
| 混合辦公 | 持續的遠距/居家辦公需求 | 中 |
| 電競市場 | 高效能PC/筆電需求 | 中 |
| 物聯網整合 | IoT閘道器、Edge設備 | 高 |
| 永續IT | 節能減碳設備更換 | 中 |

## 4. 台灣供應鏈廠商

### 4.1 整體供應鏈地位

台灣資通訊產業已形成完整的供應鏈體系：

```
上游：IC設計 → 晶圓代工 → 封裝測試
     ↓
中游：關鍵零組件（主機板、機殼、散熱、電源、面板、記憶體/儲存）
     ↓
下游：系統組裝（品牌廠 + 代工廠）
     ↓
終端：通路銷售、品牌行銷
```

台灣在以下領域具有全球主導地位：
- **EMS/ODM代工**：全球超過80%的NB由台灣代工
- **主機板**：幾乎全部由台灣廠商製造
- **電源供應器**：台灣廠商全球佔有率超過70%
- **散熱解決方案**：全球重要供應來源

## 6. SWOT分析

### 6.1 優勢（Strengths）

| 優勢項目 | 說明 |
|---------|------|
| 完整供應鏈 | 台灣擁有從IC設計到組裝的完整供應鏈，地理集中降低物流成本 |
| 技術領先 | 在NB代工、伺服器ODM、工業電腦等領域技術領先 |
| 彈性製造 | 能快速因應客戶需求變化，小量多樣生產能力強 |
| 人才優勢 | 擁有豐富的電子產業技術人才與管理經驗 |
| 產業聚落 | 新竹科學園區等產業聚落形成完整生態系 |

### 6.2 劣勢（Weaknesses）

| 劣勢項目 | 說明 |
|---------|------|
| 中國製造依賴 | 多數產能仍在中國，面臨地緣政治風險 |
| 品牌弱勢 | 除華碩、宏碁外，多數廠商以代工為主，品牌價值有限 |
| 毛利率偏低 | 代工業務利潤薄，受上游零組件價格影響大 |
| 研發投入 | 部分中小廠商研發投入不足 |
| 人才競爭 | 半導體產業搶才激烈，電子組裝業吸引力下降 |

### 6.3 機會（Opportunities）

| 機會項目 | 說明 |
|---------|------|
| AI PC需求爆發 | NPU規格升級帶動換機潮，提升ASP與毛利 |
| AI伺服器成長 | 雲端業者擴充AI基礎設施，台灣代工廠受益 |
| 邊緣運算 | Edge AI帶動IPC、嵌入式系統需求 |
| 車載電子 | 電動車/自動駕駛需要高效能運算平台 |
| 5G應用 | 5G網路普及帶動新應用場景與設備需求 |
| 全球化布局 | 供應鏈重組（美中貿易戰）下，台廠受邀至印度、東南亞設廠 |

### 6.4 威脅（Threats）

| 威脅項目 | 說明 |
|---------|------|
| 地緣政治風險 | 美中科技戰、兩岸關係影響供應鏈穩定 |
| 景氣波動 | 消費電子需求具周期性，影響訂單能見度 |
| 競爭加劇 | 中國廠商（聯想、華為、浪潮）快速崛起 |
| 晶片供應 | 先進製程晶片集中少數代工廠，供應風險高 |
| 人才短缺 | 電子業人才招募困難，影響擴產能力 |
| 匯率波動 | 新台幣匯率波動影響出口報價與匯兌收益 |

## 8. 結論與建議

### 8.1 產業總結

電腦及週邊設備產業在2024-2025年迎來復甦契機，主要受惠於：

1. **AI PC帶動升級潮**：NPU規格成為新標準，提升產品單價與毛利
2. **AI伺服器需求爆發**：雲端業者擴大AI基礎建設投資
3. **Edge運算應用擴散**：物聯網、智慧製造、智慧城市等應用帶動需求
4. **供應鏈庫存調整結束**：回到健康水位，恢復成長動能

台灣供應鏈在這波AI浪潮中扮演關鍵角色，特別是在伺服器ODM領域擁有領先技術與產能。然而，地緣政治風險、中國廠商競爭、人才短缺等挑戰仍須持續關注。

### 8.2 投資觀點

| 觀點 | 建議 |
|------|------|
| **短中期（1-2年）** | 看好AI伺服器ODM供應鏈（緯創、英業達、仁寶）、IPC廠（研華） |
| **品牌廠** | 華碩具備完整AI PC產品線，表現優於大盤 |
| **利基市場** | 神基在強固型筆電維持領先，穩定獲利 |
| **風險提示** | 宏碁為興櫃公司，流動性較低；注意地緣政治風險 |
